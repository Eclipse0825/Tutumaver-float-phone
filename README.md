# Tutuma Float Phone 1.9.4（11.27 功能更新）

本项目基于小笼包老师的 **AI Virtual Phone** 原始项目，并在 **MOMO（末末）老师的二次开发版本**基础上继续开发。

持续优化交互体验和移动端适配，整体更偏向 **Android 端的便捷操作与使用习惯**。

## 项目来源

- **原始项目 · 小笼包**：[ai-virtual-phone](https://github.com/xiaolongbao0709/ai-virtual-phone)
- **二次开发 · MOMO（末末）**：[momo.float.phone](https://github.com/jianchu-in/momo.float.phone)
- **三次开发 · Tutuma Float Phone**：基于 MOMO 二改版本继续开发与完善。

## 关于本版本

本仓库用于整理与发布 Tutuma Float Phone 的功能更新、使用说明及相关源码。

本项目并非从零开发；原版、二改及其他贡献者的成果归属于对应作者。项目保留适用的开源许可证和版权声明，第三方素材及贡献归对应权利人所有。

## 1.7.1 更新日志（包含 1.7 累计改动）

本次更新整合了 1.7 以来的功能新增、记忆系统优化和问题修复。

### 1. 跨 App 记忆系统

- 完善 Chat、短信、电话、LYSN、Weverse、iCity、X 等应用之间的记忆共享与衔接。
- 优化短期、长期及核心记忆的读取机制，减少重复内容和上下文混乱。
- 修复短信陌生号码身份混淆、电话记录重复及通话结果不完整的问题。
- 完善直播、日记、动态、多人互动等事件的记忆归属及时间判断。
- 优化角色之间的知情权限，避免无关角色读取其他人的私人经历。
- 完善部分原始事件的删除联动，已删除的来源不再进入后续短期记忆读取。

### 2. 浏览器与反查手机

- 新增浏览器及反查手机中的浏览器页面，支持相关浏览、搜索与收藏记录。
- 新增独立的反查浏览器配置绑定，支持单独设置 API、预设、世界书和翻译。
- 完善三种反查手机方式：用户邀请、角色申请、角色偷偷查看。
- 三种反查均会在 Chat 生成灰色记录卡，可查看开始时间、结束时间及实际查阅内容。
- 删除 Chat 中对应的反查记录后，会撤销该次原始查阅事件的短期记忆来源，不影响后续独立产生的聊天记录。

### 3. Chat 与好友关系

- 联系人角色卡新增 Chat 网名设置，与聊天资料保持同步。
- 新增好友名片推荐功能，可向角色介绍已有好友并建立关系线。
- 删除已发送的推荐名片时，同步解除由该名片建立的关系线。
- 角色推荐好友后产生的申请新增「取消／忽略／添加」选项。
  - **取消**：终止本次推荐的后续流程。
  - **忽略**：暂不添加，之后可能在 1–3 天内再次申请。
  - **添加**：接受申请并建立好友关系。
- 修复群语音和群视频挂断后自动触发 AI 回复的问题，挂断后直接返回群聊。

### 4. 界面与交互优化

- 调整生图相册详情页的字号和行距，改善提示词、说明与按钮的阅读体验。
- 优化独立 App 绑定页面，按照桌面应用展示配置入口。
- 统一独立 App 绑定页面的图标样式。
- 保留反查浏览器的独立绑定入口，避免与普通浏览器配置混淆。

### 5. 其他修复

- 优化跨应用事件的自动总结与来源记录。
- 改善历史事件、多人互动及匿名身份的记忆处理。
- 减少重复上下文与无效记忆注入，提高不同应用之间的互动连贯性。

## 1.9.3 更新日志（11.26 累计更新版）

本次为大规模累计更新，包含 Chat、通话美化、桌面布局、阅读、Weverse 直播、图片系统、跨应用记忆及其他应用的功能优化。

### 一、Chat 新增「线上走线下」

在原有线上聊天界面中新增面对面交流模式，无需进入原本的线下剧情页面。

- 单聊、群聊均支持线上走线下；点击聊天输入栏的「+」菜单即可开启或关闭。
- 开启后对应图标和文字高亮显示，收起菜单后仍保留开启状态。
- 按会话独立保存开关，默认关闭，不影响其他聊天；切换时不额外发送系统消息。
- 在聊天设置中可独立开启角色动作描写、自定义动作描写提示词及恢复默认提示词，并调整动作文字颜色、大小等样式。
- 动作以居中斜体文字展示，不使用普通消息气泡。
- 用户可通过 `【动作内容】` 发送自己的动作，即使关闭角色动作描写也可使用。
- 群聊支持多人共同场景及独立动作描写。
- 支持动作消息编辑、删除及重新生成；动作消息不作为普通台词引用。
- 历史面对面交流及动作保留在聊天记录和相关记忆中，关闭模式后不会改变历史消息的性质。
- 后台回复、主动消息及追发同步适配面对面模式。

本功能与原有线下剧情模式相互独立，不影响正常线上聊天。

### 二、Chat 界面与消息交互优化

- 爱心状态面板改为独立弹窗，限制弹窗尺寸，点击外部即可关闭。
- 优化 Chat 长按消息操作栏定位，统一普通聊天及小助手聊天中的操作栏定位逻辑。
- 优化语音消息引用、语音文字记录及重新生成逻辑；编辑语音文字时保留相关消息信息。
- 优化通话记录折叠后的展示布局、聊天截图及消息内容展示。
- 优化多图展开后的收起按钮位置，按照发送方区分左右两侧。
- 完善音乐、礼物、红包、转账等相关交互和内置预设规则。

### 三、内置美化及插件更新

同步更新 Kakao 经典悬浮 UI、Kakao 经典平面 UI 和 Kakao 经典键位插件（0.13.2）。

- 聊天顶部增加渐变模糊效果，使背景与顶栏过渡更加自然。
- 优化折叠通话记录样式。
- 适配线上走线下的动作文字、菜单开启状态及高亮显示。
- 兼容日间、夜间模式及旧版已选用美化。

美化与插件仍为可选功能，不强制启用，可继续使用其他自定义美化。

### 四、新增独立通话美化及实时预览

- 新增独立通话外观设置，支持对通话界面单独美化。
- 支持本地实时预览，调整时无需真正拨打电话或调用 AI。
- 同步适配单人及多人通话相关界面，实际通话与美化设置使用统一外观配置。
- 优化通话记录、折叠展示及语音文字相关逻辑。

### 五、桌面布局与主题优化

- 新增桌面网格布局调整，支持调整桌面 App 图标大小。
- 支持桌面图标重新排列及布局适配，优化文件夹图标缩放。
- 优化已有主题、自定义图标及桌面布局的兼容性。
- 补充部分小组件的内置素材，优化主题相关数据的保存及恢复。

### 六、阅读与小说

- 新增交互式直线折页翻页效果，与实际小说分页连接。
- 支持手势翻页，完成翻页后更新实际阅读页码。
- **目前翻页动画还不够完善，如果滑动翻不动，单击页边位置即可翻页。**
- 保留分享版原有小说文档读取方式。

### 七、Weverse 直播大幅更新

**直播记忆与跨应用互动**

- 完善 Weverse 直播与 Chat、日历、世界线及其他应用之间的互动衔接。
- 支持直播相关公开事件进入世界线，并在世界线中查看和编辑。
- 新增手动同步 Weverse 直播记忆功能。
- 完善直播公开内容、角色互动及相关事件记录，优化时间范围和知情边界。
- 优化预约直播与角色日程的衔接，以及直播期间相关手机操作和跨应用互动的场景逻辑。

**直播画面与动作**

- 在「内容提示词」中新增独立的 Weverse 直播画面与动作提示词。
- 支持自定义视频直播的人物动作、神态、服饰、环境、灯光、道具、音乐及镜头等描写。
- 支持多人直播中的共同动作和互动，不再强制动作与台词交替输出。
- 语音直播仍然只输出台词，不生成视频画面描写。

**直播操作与后台运行**

- 后台直播推进间隔调整为120秒。
- 新增「退出 · 艺人继续直播」选项，区分后台播放、退出观看和结束直播。

## 1.9.4 更新日志（11.27）

以下仅记录原 1.9.3 日志之后的新增和修复，不重复上一版已有功能。本轮源码已合并至 main，包含回复版本、动作格式加强、钱包及勾选样式，也记录此前已合并的后台保活、悬浮工具、通话设置折叠及阅读操作调整。本轮文档版本记为 1.9.4，未单独发布 APK。

### 一、线下剧情新增「回复版本」

单聊、群聊的线下模式均支持，入口位于角色回复下方的「重回」按钮右侧。

- 首次成功重回后才显示版本图标；未重回时不占用操作栏。
- 保留最初的回复和最近五次成功重回，最多六个版本。超出后淘汰最早的重回结果，初版始终保留；切换版本不会重置重回编号。
- 点击图标打开「回复版本」弹窗，可看正文预览、展开全文，并选择「使用此版本」。当前选择使用主题黄色标记。
- 切换直接替换原位置的回复，不新增消息，也不调用 API；正文、原始回复、语音台词及对应摘要同步恢复。
- 暂存版本会保存，退出聊天室、关闭线下模式或重新打开 APP 后仍可选择。手动插图及背景音乐不随版本重复复制。
- 切换后仍可继续重回。下一段剧情成功生成并保存后，才清除此前的暂存版本；群聊召唤及围观推进同样适用。失败、取消或空回复不会覆盖原文或增加版本。
- 只有当前选中的正文进入剧情上下文、总结、记忆及最终归档，其他暂存版本不参与。
- 编辑同步更新当前版本；删除对应回复、清空记录或成功结束归档时清理相关暂存。暂停场景仍保留版本，备份恢复及会话合并也适配暂存数据。

### 二、线上走线下：加强动作格式约束与兼容

本项是对原有动作模式的加强，同时开启「线上走线下」和「动作描写」时生效，支持单聊及群聊。

- 要求人物动作、表情、环境、场景变化等非语言内容独立使用 `【非语言描写正文】`，真正说出口的话继续使用普通台词格式，不要求动作与台词交替出现。
- 格式规则由程序固定注入。自定义动作提示词仍负责描写风格，替换自定义提示词不会移除格式要求。
- 同时兼容新的 `【动作正文】` 和旧的 `【现场动作】正文【/现场动作】`，支持连续多段、动作台词交错、多行及成对嵌套括号。
- 群聊动作继续作为共享场景展示，不误归到某个成员名下。
- 优化流式输出及重回的解析，避免尚未解析的动作片段先以普通气泡显示。
- 保留动作编辑、删除、历史读取和禁止引用动作的规则，以及语音、翻译、状态栏等原有格式。

普通线上聊天、关闭动作描写时的面对面聊天、独立线下剧情、语音和视频通话沿用各自规则。程序识别明确的动作标记，不会仅凭第三人称句子或普通括号猜测动作。

### 三、Chat 钱包支持重新开档

在钱包设置「完成」按钮下方新增「重置余额与流水」。只处理当前选中的 char 或 user 身份，不需要进入查手机。

- 适合更换 AU、经济状况或收入来源后，按当前人设重新生成基础资产和生活流水。
- 清理旧余额、多币种余额、可见流水、旧信用卡欠款及旧生成进度，重新建立账本。银行卡、当前经济配置和选填的固定收支规则保留。
- 新数据全部生成成功且账户、人设未发生变化后才替换；生成失败或期间出现新交易时保留原钱包。生成中切换账户，不会把结果写给另一个人。
- 新账本初始化不读取旧聊天、日程、订单等残留内容，后续生活流水按新账本时间范围读取相关内容，并拦截可识别的旧交易重复入账。
- 重置钱包不会删除其他 APP 的聊天、订单或平台历史本体；它们与新账本分开处理。
- 改善 user 首次资产生成：首次刷新仍只有系统默认占位金额的钱包时，按当前用户人设生成基础资产；已有真实余额或流水的钱包不会被自动重开。

### 四、钱包新增「固定收支规则 · 选填」

入口位于经济情况、收入来源下方，可填写，也可以留空。没有填写规则时仍保留原有生活收支生成。

- 支持固定收入、支出、信用卡还款及单独借款还款；可设置名称、金额、币种、每月日期或月底，以及开始、结束月份，并支持编辑、停用及删除。
- 例如「父亲的信托，每自然月收入两万元」，可直接登记为固定收入，无需每次让 AI 从自然语言中判断。
- 仅在打开、切换钱包或现有刷新操作时检查到期项目；不会为了发工资或还款增加后台定时任务，也不会额外调用 API。
- 同一规则同月只成功记账一次；漏开的月份按规则补记，短月按月底处理。余额不足的扣款保留待处理，后续检查再尝试，不伪造付款或还款。
- 借款区分本金和利息，还清后停止扣款；尚有本金时删除规则改为停用并提示，避免误删负债。
- 固定项目由程序记账，并减少 AI 再次生成相同收支的情况。重置钱包后从重置当月开始处理，不补记旧 AU 的月份。

固定规则本身不增加 API 请求；首次资产生成和重置钱包仍需要正常的模型生成。

### 五、统一勾选样式

补齐仍使用原生方框、蓝色勾的可见普通复选框，沿用现有圆形、黑色选中样式。保留原来的多选行为、键盘焦点及禁用状态；开关与隐藏输入不套用普通勾选样式。

### 六、后台保活、悬浮工具与通话设置

- 恢复独立的后台保活入口及运行逻辑，保存在设置中；通话期间协调暂停及恢复，减少与通话音频冲突。
- 优化提示词查看、快捷操作、错误诊断三个悬浮工具面板的背景可读性，统一错误诊断悬浮球的视觉样式。
- 语音、视频通话美化中的我方、对方及输入栏或通话按钮配置分组默认收起，需要时点击展开，减少页面过长。

后台保活仍受设备系统及浏览器限制，不保证锁屏或被系统终止后持续运行。

### 七、阅读翻页操作调整
